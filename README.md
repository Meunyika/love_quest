## 🌹 About The Project

**Love Quest** is a fun and interactive romantic website built using **HTML, CSS, and JavaScript**.

Instead of being a normal love message, the website turns the experience into a small interactive journey where the user answers different **YES/NO questions**.

Each answer produces a different reaction, and the journey continues until the final surprise. ❤️

The project was created as a creative way to express love through technology.

## 🎮 How It Works

The user starts by clicking:

**"I'm Ready ❤️"**

The website then presents a series of romantic questions.

For example:

```text
Do you actually love me? ❤️

[ YES ❤️ ]    [ NO 😭 ]
```

Depending on the selected answer, the website displays a different response before continuing to the next question.

At the end, the user receives:

* A love score
* An animated love meter
* A final romantic message
* A surprise button
* A confetti celebration 🎉

## 🚀 Run Locally

You don't need to install anything.

### 1. Clone the repository

```bash

```

### 2. Open the project

Go into the project folder:

```bash
cd love-quest
```

### 3. Open `index.html`

Simply double-click:

```text
index.html
```

The website will open in your browser.

## 🌐 Deploy on GitHub Pages

You can host this project for free using GitHub Pages.

### Steps

1. Create a GitHub repository.
2. Upload `index.html`.
3. Upload `README.md`.
4. Go to **Settings**.
5. Select **Pages**.
6. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
7. Click **Save**.

After deployment, GitHub will provide your website URL.

Example:

```text
https://YOUR-USERNAME.github.io/love-quest/
```

## 🎨 Customization

You can easily customize the project.

### Change the name

Find:

```html
<span class="name">My Love</span>
```

Replace `My Love` with your partner's name.

Example:

```html
<span class="name">Sarah</span>
```

---

### Change the questions

The questions are stored inside the JavaScript section:

```javascript
const questions = [
    {
        question:"Do you actually love me? ❤️",
        yes:"I knew it! 😌❤️",
        no:"Hmm... you better think again 😂",
        yesScore:10
    }
];
```

You can add as many questions as you want.

---

### Add a personal message

The final message can also be customized with your own words, memories, inside jokes, or romantic message.
